# Third-Party Code

The program bundles or depends on the following code. The license texts are in the `Licenses` folder; exported builds get all of them merged into `License.txt` (see `PostprocessBuild` in [Engine Abstraction](Engine-Abstraction#postprocessbuild-scriptspostprocessbuildcs)).

## NuGet packages (`km2 City Builder.csproj`)

| Package | Used for |
|---|---|
| `Newtonsoft.Json` | Every JSON file: core definitions, settings, presets, saved and exported cities. |
| `Antlr4.Runtime.Standard` | Runtime of the expression parser generated from the grammar (see [Runtime Calculator](Runtime-Calculator)). |
| `Delaunator` | Delaunay triangulation of terrain patches, intersections and roofs. |
| `LibGit2Sharp` | Installing and updating cores from git repositories (`CoreManager`). |

## Source code in `CustomPackages`

| Folder | Origin | Notes |
|---|---|---|
| `expressions-antlr4` | Generated by ANTLR 4 from the project's grammar | Do not edit by hand; regenerate from the `.g4` files. |
| `OBJImport` | Dummiesman's OBJ Importer (Unity asset), ported to Godot | Loads `.obj` meshes and their `.mtl` materials (`Dummiesman.OBJLoader`). |
| `RuntimeGizmo` | HiddenMonk's Unity3DRuntimeTransformGizmo (customized), ported to Godot | `TransformGizmo` (move/rotate/scale in global, local and parent space, snapping, multi-selection) and `SelectionOutline` (screen-space outline of the selected objects). Only the features the city builder uses were ported. |
| `GDExtensionWrappers` | Generated with the C# wrapper generator for GDExtension | Typed C# wrappers (namespace `GDExtension.Wrappers`) around the Terrain3D GDExtension classes. |

## Source code in `Scripts`

| File | Origin |
|---|---|
| `IO/BufferedBinaryReader.cs` | Jackson Dunstan's buffered binary reader (MIT). |
| `CityElements/Geometry/Helpers/LineSegmentIntersection.cs` | setchi's Unity-LineSegmentsIntersection (MIT), adapted for Godot. |
| `CityElements/Geometry/Helpers/PoissonDiscSampler.cs` | Gregory Schlomoff's Poisson-disc sampler (public domain), made deterministic. |
| `UI/DebugConsole/*` | yasirkula's UnityIngameDebugConsole (MIT), ported to Godot. |

## Godot addons (`addons`)

| Addon | Notes |
|---|---|
| `terrain_3d` | [Terrain3D](https://github.com/TokisanGames/Terrain3D) 1.0.1 (MIT), the heightmap terrain. `setupDependencies.ps1` (or `setupDependencies.sh` on Linux) downloads the release and extracts it into `addons` (for example to restore or update it). |
| `km2_postprocess_build` | The project's own editor plugin that registers `PostprocessBuild`. |

## Python

The embedded Python is the official Windows embeddable distribution (downloaded by `pythonInstaller/installer.ps1`). The base requirements (`pythonInstaller/requirements.txt`) only contain `psutil`, used by the server to detect when the program exits. Each core lists its own requirements and their licenses in `pythonInfo` (see [Core Structure](Core-Structure)).
